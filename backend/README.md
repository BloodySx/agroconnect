# SS Connect Backend

Backend oficial do SS Connect, desenvolvido com Node.js, TypeScript, Fastify, PostgreSQL e Prisma.

## Como executar

```bash
# Instalar dependências
npm install

# Configurar variáveis de ambiente
cp .env.example .env

# Executar migrations
npm run prisma:migrate

# Iniciar em desenvolvimento
npm run dev
```

## Stack

- Node.js
- TypeScript
- Fastify
- PostgreSQL
- Prisma ORM
- Zod
